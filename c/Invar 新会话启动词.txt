## 四、必须继承的外部理论与安全边界

- **双主体对比实验（Dual-Subject Differential Testing）**：检测 BOLA/IDOR 必须通过 Token A 与 Token B 的交叉请求，计算响应结构相似度（SequenceMatcher），彻底消除 200 OK 误报。
- **语义解耦逃逸（Semantic Desynchronization）**：利用 `X-HTTP-Method-Override` 等隧道技术刺探 WAF 与后端框架的动词解析差异。
- **有证据才晋级（Promotion Gate）**：坚决拒绝 AI 幻觉，只有被底层 HTTP 报文事实击穿并判定为 `VERIFIED` 的假设，才能生成知识卡片。

## 五、踩过的坑，后续绝对不要再踩

1. **Windows 命令行截断陷阱**：严禁通过 CLI 参数传递 JSON，必须使用匿名管道（`Stdio::piped()`）流式传输。
2. **IPC 死锁**：Python 子进程必须全局捕获异常并返回 JSON 错误包，严禁抛出原生 Traceback 导致 Rust 读端永久挂起。
3. **单进程性能灾难**：严禁在循环中频繁 Spawn 子进程，必须使用 `execute_batch` 走单次进程批量通信。
4. **测试目录污染**：Rust 集成测试必须放在 `crates/tests/`，严禁放回 `src/`。
5. **动态字典腐烂**：跨语言边界必须使用强类型 Struct/Dataclass，拒绝无边界的 `dict` 裸奔。
